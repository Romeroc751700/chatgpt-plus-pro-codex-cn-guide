## 开通后怎样验收是真正的本人账号订阅？

在 ChatGPT 官方网站或官方 App，确认当前登录的账号与订单对应账号一致，然后查看套餐、计费或订阅管理页，核对档位与本次有效期。Codex 用户再检查自己的 Usage、重置时间以及实际登录方式。

- **原订单显示已付款**：说明付款状态，不单独证明套餐生效。
- **原订单已发卡**：Pro100 还需要按说明完成兑换，或让客服协助。
- **人工处理中**：Pro200 按原订单继续处理，不是让用户等待一张不存在的自动卡密。
- **官网已经显示本次套餐**：这是账号侧验收；额度、模型与功能仍按当前官方规则及账号显示核验。

状态不清楚时先查原订单和同一账号，不要重复付款。详见[Pro 付款与到账核验](docs/chatgpt-pro-cn-payment.md)。

## Codex 用量不够，是买 Pro 还是 API？

先看**认证方式**，不是简单看“用了客户端还是服务器”。Codex CLI 可以用 ChatGPT 账号登录，也可以使用 API key；前者核对订阅包含用量，后者核对 API 独立账单。购买 Pro 不会给 API Platform 充值，个人 ChatGPT credits 也不等于 API 余额。

再看**实际限制**：当前套餐、模型、任务规模、用量界面与重置时间。如果登录了错误账号或用错计费方式，先解决这个问题；确定订阅包含用量持续影响工作时，再比较 Pro100、Pro200。不能拿旧估算表换算出每个人固定能完成多少个任务。
